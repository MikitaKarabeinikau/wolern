✨ Features
🎯 Core Features

- Vocabulary Management

  ** Add, edit, and delete words with translations
  ** Multiple definitions with categories
  ** Example sentences with context
  ** Synonyms and tags
  ** Usage warnings and notes
  ** Part of speech classification
  \*\* Spaced Repetition System

4-stage learning progression
Intelligent review scheduling
Progress tracking (correct/incorrect answers)
Adaptive difficulty based on performance
Exercise Generation

AI-powered exercise creation
Multiple choice questions
Answer input exercises
Contextual hints
Detailed explanations
Quiz System

Real-time progress tracking
Visual feedback for answers
Character-by-character comparison
Learning stage advancement/demotion
Review date scheduling
User Management

Clerk authentication integration
User-specific vocabulary lists
Exercise quota system (10 exercises per user)
Personal progress tracking
